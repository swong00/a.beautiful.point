The first reusable visual pattern is a flow:

1. Start with a messy real-world problem.
2. Collect the data signal.
3. Build the system model.
4. Create an interactive or diagrammatic explanation.
5. Name the beautiful point.
6. Translate it into a software pattern or action.

This is the lab's default artifact grammar. Future visuals can become more specific, but the first version should make the publishing loop clear.
