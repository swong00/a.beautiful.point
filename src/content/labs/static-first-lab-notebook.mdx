The lab starts with local files, static pages, and checked-in artifacts. This keeps ideas portable and inspectable while the editorial system is still forming.

Prototype candidates:

- a causal map sketch for incidents,
- a small reliability signal classifier,
- a static dataset that feeds a diagram,
- an interactive decision surface for operational triage.

Each prototype should support a specific essay, visual, or systems argument.
