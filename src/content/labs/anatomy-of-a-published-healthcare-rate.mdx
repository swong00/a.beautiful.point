Since 2022, US health insurers have been required to publish machine-readable
files listing the rates they have negotiated. The files exist, they are
enormous, and they are routinely read as price lists. They are not price
lists. Each line is a narrow, specific statement: *this file, for this
reporting month, attached this number to this billing code in this context.*

This lab dissects real records from that system: a bounded slice of
**12,183 retained monetary negotiated-rate facts** from eight Cigna Colorado
in-network files for reporting month July 2026, filtered to fifteen exact CPT
codes. The default view is CPT 99204, a common new-patient office visit, with
1,994 retained facts. Every value on this page comes from checked-in assets
pinned to a validated pipeline release — nothing is fetched, estimated, or
aggregated.

The interesting part of a published rate is not the number. It is how much
surrounding context is missing by the time the number reaches you. The source
schema itself does not state a currency. And this bounded slice retains none
of the billing-code-modifier, care-setting, or plan context — context the CMS
file format can carry, and which the underlying files do publish in part —
so a matching CPT code alone tells you less than it appears to. Below, one
real record is annotated field by field — what each field establishes, and
what it quietly does not.
